# 国内外主流大模型能力对比

整理时间：2026-11-09（Asia/Shanghai）

> 本版按 2026-11-09 官方模型目录、发布页和 API 文档复核。不同 benchmark 的 harness、工具和推理预算不同，不把不同厂商分数直接相减；未公开数据明确标注。

## 一、国外厂商

### OpenAI：GPT-6 Astra / GPT-6.1 Sol / GPT-6.1 Terra / GPT-6 Luna

- 发布时间：Astra 2026-09-03；6.1 Sol 2026-09-29；6.1 Terra 2026-10-26；Luna 2026-09-22。
- 定位：Astra 为复杂推理、Coding、浏览和 Computer Use 旗舰；6.1 Sol 为近 Astra 的平衡档；Terra 为视觉推理和精确 Computer Use 的效率档；Luna 为高并发低价档。
- Coding/推理：官方统一定位覆盖 software engineering、science、computer use；当前目录未公开完整统一 GPQA/AIME 表。
- 多模态：文本/图像输入；语音、图像生成、视频由 GPT Live、GPT Image、Sora 专用端点提供。
- 长上下文：1.05M，最大输出 128K；推理 token、工具结果与输出共同占用窗口。
- Agent/工具：Responses、函数调用、Web/File Search、Code Interpreter、Hosted Shell、Computer Use、MCP、Multi-agent。
- 开源/部署：闭源，API/云托管，不支持本地加载权重。
- 价格：Astra $10/$50；6.1 Sol $2/$10；6.1 Terra $1/$5；Luna $0.1/$0.5（每百万输入/输出 token，缓存和长提示另计）。
- 来源：[模型目录](https://developers.openai.com/api/docs/models)、[GPT-6 指南](https://developers.openai.com/api/docs/guides/latest-model)、[10 月变更](https://developers.openai.com/api/docs/changelog)。

### Anthropic：Claude Fable 5.1 / Mythos 5.1 / Opus 5.5 / Sonnet 5.5 / Haiku 5.5

- 发布时间：Fable/Mythos 5.1（2026-09-01）；Opus 5.5（09-22）；Sonnet 5.5（09-28）；Haiku 5.5（10-07）。
- 定位：Fable/Mythos 为最高端 Coding 与知识工作型号；Opus 5.5 为公开旗舰；Sonnet 5.5 为主流 Agent；Haiku 5.5 为高并发子 Agent。
- Coding/推理：Sonnet 5.5 官方 Terminal-Bench 4.0 为 70.6%；Fable/Mythos 的完整数字以对应 system card 为准，不能套用 4.x 结果。
- 多模态：图像/文档理解；浏览器、终端、Computer Use、MCP 工具成熟，非原生视频生成。
- 长上下文：Opus 页面标注 1M；实际效果取决于缓存、压缩与工具轨迹。
- Agent/工具：浏览器、终端、Computer Use、MCP、函数调用。
- 开源/部署：闭源；Anthropic API、AWS、Google Cloud、Microsoft Foundry。
- 价格：Opus 5.5 $4/$20；Sonnet 5.5 $2/$10；Haiku 5.5 $0.10/$0.50；Fable/Mythos 需按受限访问价格确认。
- 来源：[Anthropic 新闻](https://www.anthropic.com/news)、[系统卡](https://www.anthropic.com/system-cards)、[Fable/Mythos 系统卡](https://www-cdn.anthropic.com/d00db56fa754a1b115b6dd7cb2e3c342ee809620/Claude%20Fable%205%20%26%20Claude%20Mythos%205%20System%20Card.pdf)。

### Google：Gemini 3.8 Flash / Gemini 3.1 Pro

- 状态：3.8 Flash 为 Stable 主力；3.1 Pro 为 Preview 高推理型号。
- 定位：Flash 偏长任务、Agent 和吞吐；Pro 偏复杂推理、Coding 和多模态。
- 多模态：图像、音频、视频输入；Gemini Live、TTS、图像和视频模型形成组合。
- 长上下文：输入 1M、输出 64K，支持 Context Caching。
- Agent/工具：Search、Maps、File Search、URL Context、Code Execution、Computer Use、Function Calling。
- 开源/部署：闭源，AI Studio、Gemini API、Vertex AI。
- 价格：3.1 Pro $2/$12（≤200K）或 $4/$18（>200K）；Flash 按具体型号实时价。
- 来源：[模型列表](https://ai.google.dev/gemini-api/docs/models)、[Gemini 3 指南](https://ai.google.dev/gemini-api/docs/gemini-3)。

### xAI、Meta、Mistral

- Grok 4.7（2026-09-21）：Coding、知识工作、长任务自校验；500K context；$2/$6 短上下文、$4/$12 长上下文；闭源。[发布](https://x.ai/news/grok-4-7) · [价格](https://docs.x.ai/developers/pricing)
- Llama 4 Scout/Maverick（2025-04-05）：开放权重原生图文，Scout 标称 10M context，Maverick 偏质量/成本；可 vLLM/SGLang/Transformers 本地部署。[发布](https://ai.meta.com/blog/llama-4-multimodal-intelligence/)
- Mistral Large 4（官方总览 v26.10）：开放权重、多模态、256K context、函数调用和 Agents；Apache 2.0 生态。[总览](https://docs.mistral.ai/models)

## 二、国内厂商

### DeepSeek：V4.1-Flash-1017（API：`deepseek-flash`）

- 发布时间：2026-10-17；截至本次核验仍是最新正式更新。
- 定位：国内最新 Coding/Agent/视觉理解高性价比主力。
- Coding/推理：Terminal-Bench 4.0 42.3、DeepSWE v1.1 77.0、HLE 无工具 42.6；官方注明使用 Claude Code、Mini-SWE 等 harness。
- 多模态：原生 Vision；1M context，最大输出 384K。
- Agent/工具：Thinking + Tool Use、Responses API、Anthropic 兼容、Search/Fetch、Codex/CodeBuddy 适配。
- 开源/部署：权重已发布 Hugging Face/ModelScope；552B 总参数，私有化需核算 GPU/带宽。
- 价格：峰谷、缓存命中/未命中和输出分开计费，Search/Fetch 另按请求计费。
- 来源：[10 月 17 日更新](https://api-docs.deepseek.com/news/news261017/)、[价格](https://api-docs.deepseek.com/quick_start/pricing/)。

### 阿里云 Qwen：Qwen3.8-Max / Qwen3.8-Omni-Flash

- 发布时间：Max 2026-08-03；Omni-Flash 2026-09-18。
- 定位：Max 为文本/Coding/长程 Agent 旗舰；Omni-Flash 为图像、音频、视频和音频输出主力。
- 长上下文：Max/Plus 多为 1M；Omni-Flash 当前 65,536，不能混写。
- Agent/工具：Web Search、Function Call、Realtime API、Qwen Agent/MCP。
- 开源/部署：Qwen3.8-Max 官方称开放权重发布；Qwen 生态支持 vLLM/SGLang/Ollama，许可证按版本确认。
- 价格：按 model ID 和上下文档位实时计费。
- 来源：[Qwen API](https://qwen.ai/apiplatform)、[Qwen3.8-Max](https://qwen.ai/blog?id=qwen3.8)。

### MiniMax：MiniMax-M3

- 发布时间：2026-06-01；定位为同时覆盖 Coding、Agent、1M context、原生多模态的开放权重主力。
- Coding/推理：长时自主代码任务、工具调用、搜索和 MaxProof 数学路线；BrowseComp 83.5。
- 多模态：文本、图像、视频、音频输入；H3 为独立视频生成模型。
- 长上下文：最多 1M，保证至少 512K，MSA 稀疏注意力。
- Agent/工具：任务分解、工具调用、MiniMax Code、Agent Team。
- 开源/部署：官方称开放 Hugging Face/GitHub 权重，支持私有集群和微调；以仓库实际状态为准。
- 价格：旧版 M2.5 价格不适用于 M3，采购前查 M3 实时价。
- 来源：[M3 模型页](https://www.minimax.io/models/text/m3)、[发布记录](https://ir.minimax.io/news-events/new-releases)。

### Moonshot、智谱、百度

- Moonshot：官方状态页列出 K3、K2.8 Preview、K2.7 Code Highspeed 在运行，但 K3 的完整公开型号卡、benchmark、窗口和价格尚不齐全；不能用 K2.5 旧数据代替。[状态页](https://status.moonshot.cn/)
- 智谱：公开产品页可核到 GLM-5.2、GLM-5-Turbo；Coding、中文 Agent 和办公自动化是突出方向，但统一 SWE/GPQA/AIME、窗口和价格需实时模型卡确认。[官方页](https://open.bigmodel.cn/claw-plan-team)
- 百度：ERNIE 5.1（2026-05-09）主打中文知识、搜索和原生全模态企业应用；公开资料没有稳定统一的 SWE/GPQA/AIME、窗口和 token 价格表。[官方发布](https://ernie.baidu.com/blog/posts/ernie-5.1-0508-release/)

## 三、组内横向总结

| 维度 | 国外优先选择 | 国内优先选择 |
|---|---|---|
| 编程/软件工程 | Claude Fable/Mythos 5.1、GPT-6 Astra | DeepSeek V4.1-Flash-1017、Qwen3.8-Max、MiniMax M3 |
| 深度推理/数学 | Claude Fable/Mythos 5.1、GPT-6 Astra、Gemini 3.1 Pro | DeepSeek V4.1-Flash-1017、MiniMax M3 |
| 多模态 | Gemini 3.8/3.1 | Qwen3.8-Omni-Flash、MiniMax M3、ERNIE 5.1 |
| 长上下文 | Llama 4 Scout（标称 10M）；GPT/Gemini/Claude（1M 级） | DeepSeek、Qwen Max、MiniMax M3（1M 级） |
| Agent/工具 | GPT-6 Astra、Claude 5.x、Gemini 3.x | DeepSeek、Qwen、MiniMax |
| 开源/本地化 | Llama 4、Mistral Large 4 | DeepSeek、Qwen、MiniMax |
| 性价比 | Claude Sonnet/Haiku 5.5、Gemini Flash、GPT-6 Luna | DeepSeek Flash、MiniMax M3、Qwen Flash/Plus |

## 四、选型结论

1. 高质量 Coding Agent：国外优先 Fable/Mythos 5.1、GPT-6 Astra；国内优先 DeepSeek V4.1-Flash-1017、Qwen3.8-Max、MiniMax M3。
2. 多模态生产：国外优先 Gemini；国内优先 Qwen Omni 或 MiniMax M3，视频生成另选专用模型。
3. 私有化：优先 Llama 4、Mistral、DeepSeek、Qwen、MiniMax；闭源模型只能托管或商业私有化。
4. 采购前复核 model ID、正式/Preview、thinking/output 是否共享窗口、缓存/区域价格、并发和许可证。
