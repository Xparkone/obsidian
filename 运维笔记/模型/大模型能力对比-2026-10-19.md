# 国内外主流大模型能力对比（更新版）

整理时间：2026-10-19（Asia/Shanghai）

> 本版只把截至当天能在厂商官方模型页、官方新闻或官方 API 文档中核到的型号列为“当前主力”。Preview、滚动别名、历史型号和第三方榜单分开标注。benchmark 受 harness、工具、推理预算影响，不能把不同厂商自报百分数直接相减。

## 一、国外厂商

### OpenAI：GPT-6 Astra / GPT-6.1 Sol

- 发布时间：GPT-6 Astra 2026-09-03；GPT-6.1 Sol 于 2026-10-08 进入 API 更新记录。
- 定位：Astra 是最强端到端推理、编程、浏览和 Computer Use；6.1 Sol 是更低成本的复杂 Coding/Agent 主力。
- 编程/推理：官方定位覆盖 software engineering、science、computer use；统一 GPQA/AIME 数字未在当前模型页完整公开，需按官方最新评测表复核。
- 多模态：文本与图像输入；工具侧支持图像生成、语音、实时会话等专用端点，Astra/Sol 本身不是视频生成模型。
- 长上下文：GPT-6 家族约 1M 级；推理 token、工具结果与输出共同消耗窗口，长上下文价格另计。
- Agent/工具：Responses API、函数调用、Web/File Search、Code Interpreter、Hosted Shell、Computer Use、MCP、Tool Search。
- 开源/部署：闭源，API、云平台托管，不支持权重本地部署。
- 价格档位：Astra 旗舰高价档；6.1 Sol 为中高价档；当前 OpenAI 价格页应以 `gpt-6-astra`、`gpt-6.1-sol` 实时表为准。
- 依据：[OpenAI GPT-6 指南](https://developers.openai.com/api/docs/guides/latest-model)、[API 变更记录](https://developers.openai.com/api/docs/changelog)。

### Anthropic：Claude Opus 5.5 / Sonnet 5.5 / Haiku 5.5

- 发布时间：Opus 5.5（2026-09-22）、Sonnet 5.5（2026-09-28）、Haiku 5.5（2026-10-07）。
- 定位：Opus 5.5 是复杂工作和长任务 Agent 旗舰；Sonnet 5.5 是主流 Coding/文档 Agent；Haiku 5.5 是高并发低成本子 Agent。
- 编程/推理：Sonnet 5.5 官方 Terminal-Bench 4.0 为 70.6%；Opus 5.5 官方定位为 Claude 当前最强 Opus。GPQA/AIME 需按 5.5 系列 system card 口径使用，不能沿用 4.x 数据。
- 多模态：图像/文档理解；工具与产品可组合语音、浏览器和代码执行，非原生视频生成。
- 长上下文：Opus 页面标注 1M context；实际有效性仍受缓存、压缩和工具轨迹影响。
- Agent/工具：浏览器、终端、MCP、函数调用、Computer Use，适合长时间多步执行。
- 开源/部署：闭源，Anthropic API、AWS、Google Cloud、Microsoft Foundry。
- 价格档位：Opus 5.5 $4/$20；Sonnet 5.5 $2/$10；Haiku 5.5 $0.10/$0.50（每百万输入/输出 token，部分长提示和缓存有单独价格）。
- 依据：[Opus 5.5](https://www.anthropic.com/claude-opus-5-5)、[Sonnet 5.5](https://www.anthropic.com/claude-sonnet-5-5)、[Haiku 5.5](https://www.anthropic.com/claude-haiku-5-5)。

### Google：Gemini 3.8 Flash / Gemini 3.1 Pro

- 发布时间/状态：3.8 Flash 为当前 Stable 主力；3.1 Pro 为 Preview 旗舰推理型号。
- 定位：3.8 Flash 偏长任务、Agent 和吞吐；3.1 Pro 偏复杂推理、Coding 和多模态。
- 编程/推理：官方将 3.1 Pro 定位为 advanced intelligence、complex problem solving、agentic/vibe coding；当前页面未给出所有 GPQA/AIME 的统一历史序列。
- 多模态：图像、音频、视频输入；Gemini Live、TTS、图像生成和 Omni/视频模型形成完整多模态组合。
- 长上下文：Gemini 3 系列输入 1M、输出 64K；支持 Context Caching。
- Agent/工具：Google Search、Maps grounding、File Search、URL Context、Code Execution、Computer Use、Function Calling。
- 开源/部署：闭源，Google AI Studio、Gemini API、Vertex AI。
- 价格档位：3.1 Pro $2/$12（≤200K）或 $4/$18（>200K）；3.x Flash 为低价档，按具体版本实时表确认。
- 依据：[模型列表](https://ai.google.dev/gemini-api/docs/models)、[Gemini 3 指南](https://ai.google.dev/gemini-api/docs/gemini-3)。

### xAI：Grok 4.7

- 发布时间：2026-09-21。
- 定位：Coding、知识工作、长任务自校验和 Grok Build/Cursor Agent。
- 编程/推理：官方展示 CursorBench 4.0 价格性能；完整 SWE/GPQA/AIME 需使用同一 harness 复测。
- 多模态：Grok 产品支持图像/视频生成、图像理解和 Voice；API 按端点区分。
- 长上下文：500K；输入达到 200K 后进入长上下文价格档。
- Agent/工具：实时 Web/X 搜索、Connectors、Grok Build、代码工具。
- 开源/部署：闭源，xAI API 和合作平台。
- 价格：短上下文 $2/$6；长上下文 $4/$12。
- 依据：[Grok 4.7](https://x.ai/news/grok-4-7)、[API 价格](https://docs.x.ai/developers/pricing)。

### Meta：Llama 4 Scout / Maverick

- 发布时间：2025-04-05；截至本次核验仍是 Meta 官方开放权重主力家族。
- 定位：Scout 主打单卡和超长上下文；Maverick 主打开放权重多模态质量/成本。
- 编程/推理：Maverick 官方称在推理与 Coding 接近 DeepSeek-V3；教师模型 Behemoth 的 GPQA/MATH 结果不能当作已开放模型结果。
- 多模态：原生图文；音频、视频生成需外接模型。
- 长上下文：Scout 10M；Maverick 1M 级。真实召回能力需用量化权重和业务语料验证。
- Agent/工具：Llama Stack、函数调用、Transformers/vLLM/SGLang 生态。
- 开源/部署：开放权重，可本地部署；Scout Int4 可单 H100，Maverick 适合多 GPU。
- 价格：无统一官方 API 价，按云厂商/推理服务商计费。
- 依据：[Llama 4 官方发布](https://ai.meta.com/blog/llama-4-multimodal-intelligence/)。

### Mistral：Mistral Large 4

- 发布时间：官方模型总览当前标注 v26.10。
- 定位：开放权重、通用、多模态旗舰；代码 Agent 可另看 Devstral 系列。
- 编程/推理：支持结构化输出、函数调用和 Agent；公开 GPQA/AIME 统一表有限。
- 多模态：图像/文档理解；OCR、转写和语音由专用模型承担。
- 长上下文：官方模型页当前为 256K；超窗请求直接返回 400，输入输出共同计入。
- Agent/工具：Function Calling、Agents & Conversations、Mistral Code/CLI。
- 开源/部署：开放权重，Apache 2.0 生态，可 vLLM/SGLang/Transformers 私有化。
- 价格：Large 4 当前需以官方价格页实时型号卡为准；Large 3 官方价曾为 $0.5/$1.5。
- 依据：[Mistral 模型总览](https://docs.mistral.ai/models)、[价格页](https://docs.mistral.ai/inference/pricing)、[上下文限制](https://docs.mistral.ai/resources/known-limitations)。

## 二、国内厂商

### DeepSeek：DeepSeek-V4.1-Flash-1017（API 名 `deepseek-flash`）

- 发布时间：2026-10-17，当前核验到的最新正式更新。
- 定位：编程、Agent、视觉理解和成本效率兼顾的主力；官方称较 V4.1 有性能/成本 Pareto 改善。
- 编程/推理：Terminal-Bench 4.0 42.3、DeepSWE v1.1 77.0、HLE（无工具）42.6；这些结果分别使用 Claude Code/Mini-SWE 等 harness，不能与裸模型分数直接比较。
- 多模态：原生视觉理解；官方当前型号页支持 Vision。
- 长上下文：官方价格页标注 1M context、最大输出 384K。
- Agent/工具：Thinking + Tool Use、Responses API、Anthropic 兼容接口、DeepSeek Search/Fetch、Codex/CodeBuddy 适配。
- 开源/部署：V4.1-Flash-1017 权重已发布 Hugging Face/ModelScope；大规模本地部署仍需评估 552B 总参数模型的 GPU/带宽成本。
- 价格：以官方峰谷价格表为准，缓存命中/未命中与输出分开计费；Search/Fetch 另按请求计费。
- 依据：[10 月 17 日更新](https://api-docs.deepseek.com/news/news261017/)、[变更日志](https://api-docs.deepseek.com/updates/?release=deepseek-coder)、[价格页](https://api-docs.deepseek.com/quick_start/pricing/)。

### 阿里云 Qwen：Qwen3.8-Max / Qwen3.8-Omni-Flash

- 发布时间：Qwen3.8-Max 2026-08-03；Qwen3.8-Omni-Flash 2026-09-18。
- 定位：Max 是 Qwen 当前文本、Coding、长程 Agent 旗舰；Omni-Flash 是图像/音频/视频输入和工具调用主力。
- 编程/推理：Qwen3.8-Max 官方称为家族当前最强；发布页给出复杂 Coding、研究和长程任务提升。具体 GPQA/AIME 需按官方技术报告版本核对。
- 多模态：Omni-Flash 原生文本、图像、音频、视频输入并支持音频输出；另有 Qwen-Image、TTS、ASR、LiveTranslate。
- 长上下文：Qwen API 当前 Max/Plus 多为 1M；Omni-Flash 当前页面为 65,536，不能把全家族窗口混写。
- Agent/工具：Web Search、Function Call、Realtime API、Qwen Agent/MCP。
- 开源/部署：Qwen3.8-Max 官方称开放权重将发布；Qwen3/3.8 系列生态可用 vLLM、SGLang、Ollama，具体许可证按权重版本确认。
- 价格：按 QwenCloud/Qwen API 的 model ID 和上下文档位计费；当前页面没有一个可覆盖全系列的统一单价，采购前查实时价格表。
- 依据：[Qwen API 当前型号](https://qwen.ai/apiplatform)、[Qwen3.8-Max 发布](https://qwen.ai/blog?id=qwen3.8)。

### MiniMax：MiniMax-M3

- 发布时间：2026-06-01。
- 定位：国内当前少数同时把 Coding、Agent、1M context 和原生多模态放在同一个开放权重模型中的主力。
- 编程/推理：官方展示长时自主代码任务、工具调用和搜索；M3 配套 MaxProof 数学证明路线，具体分数应以技术报告为准。
- 多模态：原生文本、图像、视频、音频输入；H3 为独立视频生成模型。
- 长上下文：API 支持最多 1M，官方保证至少 512K；采用 MSA 稀疏注意力。
- Agent/工具：自主任务分解、工具调用、MiniMax Code、Agent Team；官方 BrowseComp 83.5。
- 开源/部署：官方称开放 Hugging Face、GitHub 权重，支持私有集群和微调；部署状态以仓库实际可下载版本为准。
- 价格：官方模型页当前应以 M3 API 实时价格为准；旧版 M2.5 的 $0.15/$1.2 不应继续套用到 M3。
- 依据：[M3 官方模型页](https://www.minimax.io/models/text/m3)、[M3 发布记录](https://ir.minimax.io/news-events/new-releases)。

### Moonshot AI：K3 / K2.8 Preview

- 当前状态：Moonshot 官方状态页（2026-10-19）显示 K3、K2.8 Preview、K2.7 Code Highspeed 均在运行；公开技术规格和统一 benchmark 资料不完整。
- 定位：K3 为当前服务中的最新 Kimi 系列主力；K2.8 Preview/ K2.7 Code Highspeed 分别偏预览能力和 Coding 速度。
- 编程/推理/多模态/长上下文/价格：截至整理日没有足够完整的官方公开型号卡，不能用旧版 K2.5 数据冒充 K3 当前数据。
- Agent/工具：Kimi 产品线提供搜索、文件、代码和 Agent 能力；具体工具集合需以 API model ID 文档为准。
- 开源/部署：K2.5 论文与权重曾公开；K3/K2.8 是否开放权重尚未从官方型号卡确认。
- 依据：[Moonshot 官方状态页](https://status.moonshot.cn/)。

### 智谱 AI：GLM-5.2 / GLM-5-Turbo

- 截至本次核验，智谱官方公开页面仍以 GLM-5.2、GLM-5-Turbo 为主要产品型号；未找到可确认的 GLM-5.3 官方 API 型号卡。
- 定位：GLM-5.2 偏中文通用/推理/Agent；GLM-5-Turbo 偏高吞吐和企业工作流。
- 编程/推理：官方产品页强调 Coding、智能体、数理推理和办公自动化，但公开 SWE/GPQA/AIME 同口径数据有限。
- 多模态：图像、PPT/文档和办公场景能力由产品体系提供，具体模型端点需单独核对。
- 长上下文/价格：不同渠道和活动套餐差异明显，当前无法从公开页面确认统一可比数值，应以智谱开放平台实时模型卡为准。
- Agent/工具：工具协同、代码执行、定期任务和企业 Agent 是主要卖点。
- 开源/部署：GLM 部分家族有开放权重；5.2/Turbo 服务版权重是否开放，当前公开资料未确认。
- 依据：[智谱官方产品页](https://open.bigmodel.cn/claw-plan-team)。

### 百度：ERNIE 5.1

- 发布时间：2026-05-09。
- 定位：中文知识、搜索增强和原生全模态企业应用主力。
- 编程/推理：官方发布稿称多项榜单领先，但当前公开材料没有稳定可复验的 SWE-bench/GPQA/AIME 统一表。
- 多模态：ERNIE 5 路线强调 native omni-modal，覆盖图像、语音和视频产品能力；API 需按具体端点区分。
- 长上下文/Agent/价格：千帆模型卡与套餐实时变化，公开发布稿不足以确认统一窗口和每百万 token 价格。
- 开源/部署：闭源为主，通过千帆和百度智能云提供托管/企业方案。
- 依据：[ERNIE 5.1 发布](https://ernie.baidu.com/blog/posts/ernie-5.1-0508-release/)。

## 三、组内横向结论

| 维度 | 国外优先选择 | 国内优先选择 |
|---|---|---|
| 编程/软件工程 | Claude Opus 5.5、GPT-6 Astra | DeepSeek V4.1-Flash-1017、Qwen3.8-Max、MiniMax M3 |
| 深度推理/数学 | GPT-6 Astra、Gemini 3.1 Pro、Claude Opus 5.5 | DeepSeek V4.1-Flash-1017、MiniMax M3 |
| 多模态 | Gemini 3.8/3.1 系列 | Qwen3.8-Omni-Flash、MiniMax M3、ERNIE 5.1 |
| 长上下文 | Llama 4 Scout（10M 标称）；GPT/Gemini/Claude（1M 级） | DeepSeek、Qwen Max、MiniMax M3（1M 级） |
| Agent/工具 | GPT-6 Astra、Claude 5.5、Gemini 3.x | DeepSeek、Qwen、MiniMax |
| 开源/本地化 | Llama 4、Mistral Large 4 | DeepSeek、Qwen、MiniMax |
| 性价比 | Claude Sonnet/Haiku 5.5、Gemini Flash、GPT-6.1 Sol | DeepSeek Flash、MiniMax M3、Qwen Flash/Plus |

## 四、选型与更新说明

1. 高质量 Coding Agent：国外优先 Claude Opus 5.5/GPT-6 Astra；国内优先 DeepSeek V4.1-Flash-1017、Qwen3.8-Max、MiniMax M3。
2. 私有化：优先 Llama 4、Mistral、DeepSeek、Qwen、MiniMax；闭源模型只能走托管或商业私有化方案。
3. 采购前重新核对 model ID、正式/Preview 状态、窗口是否共享 thinking/output、缓存价格、并发和许可证。
4. 已删除上一版中被新型号替代或无法确认当前状态的旧型号表述；对 Moonshot、智谱、百度公开资料不足的维度明确写“尚未确认”。
