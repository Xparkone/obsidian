# 国内外主流大模型能力对比

整理时间：2026-10-19（Asia/Shanghai）

> 范围：选取截至整理日仍在官方文档、API 或产品页中提供的主力/旗舰模型。价格统一按美元、每百万 token（输入/输出）记录；国内厂商同时保留人民币或官方页面口径。不同厂商的 benchmark 使用的 harness、工具、推理预算和数据切分不同，不能把百分数当作严格同场排名。

## 一、国外厂商

### 1. OpenAI — GPT-5.6 Sol

- 发布时间/定位：2026-06-26 开始预览，2026-07-29 发布效率与定价说明；旗舰通用推理、专业工作和 Coding 模型。
- 编程：官方称在 Terminal-Bench 2.1 达到当时 SOTA；适合 Codex、代码修改、Shell、Computer Use 和多步工程任务。
- 深度推理与数学：支持 none/low/medium/high/xhigh/max 推理档位；官方模型页未给出统一的 GPQA/AIME 单一口径，不能据此与其他厂商自报分数硬排。
- 多模态：文本输出、图像输入；可通过 Responses API 调用图像生成、语音转写等独立能力，模型本身不接收音频/视频。
- 长上下文：1,050,000 tokens；最大输出 128K。超过 272K 输入 token 时进入长上下文价格档位，实际可用性受推理 token、工具结果和输出预算共同占用影响。
- Agent/工具：原生 function calling、Web/File search、Code interpreter、Hosted shell、Apply patch、Computer use、MCP、Tool search。
- 开源/本地化：权重闭源；可通过 OpenAI API、Azure/Bedrock 等托管渠道部署，不能本地运行。
- 价格：标准 $4 / $20；长上下文 $4 / $20（官方当前页标示优惠价至少至 2026-11-21）。
- 依据：[模型页](https://developers.openai.com/api/docs/models/gpt-5.6-sol)、[发布说明](https://openai.com/index/previewing-gpt-5-6-sol/)、[效率与价格](https://openai.com/index/gpt-5-6-frontier-intelligence-efficiency/)。

### 2. Anthropic — Claude Opus 4.7

- 发布时间/定位：2026 年发布（官方系统卡为当前型号）；长任务、软件工程、研究与 Agent 旗舰。
- 编程：官方系统卡 SWE-bench Verified 87.6%、SWE-bench Pro 64.3%、SWE-bench Multilingual 80.5%；适合大型仓库、多文件重构和代码审查。
- 深度推理与数学：GPQA Diamond 94.2%；Humanity’s Last Exam 无工具 46.9%、有工具 54.7%。AIME 的公开结果受 extended thinking 和提示词影响，使用时应记录推理预算。
- 多模态：图像理解、文档/图表理解；无原生视频生成，语音通常通过产品或外围 API 组合。
- 长上下文：Claude 4 系列支持 200K，部分配置支持 1M；官方提示长上下文会使用单独价格档位，实际效果仍取决于上下文压缩、检索和工具轨迹。
- Agent/工具：tool use、Computer Use、MCP 生态成熟；官方评测中 MCP Atlas 62.7%、BrowseComp 多智能体 harness 86.8%。
- 开源/本地化：权重闭源；通过 Anthropic API、Bedrock、Vertex AI 提供托管访问。
- 价格：Opus 4.7 约 $15 / $75（≤200K），1M 长上下文约 $30 / $300；价格以官方当日价格页为准。
- 依据：[Opus 4.7 系统卡](https://www-cdn.anthropic.com/037f06850df7fbe871e206dad004c3db5fd50340/Claude%20Opus%204.7%20System%20Card.pdf)、[Opus 4.6 发布与评测口径](https://www.anthropic.com/news/claude-opus-4-6)、[价格页](https://docs.anthropic.com/en/docs/about-claude/pricing)。

### 3. Google — Gemini 3.1 Pro

- 发布时间/定位：2026 年 Gemini 3 系列 Preview；复杂问题、代码和原生多模态的旗舰模型。
- 编程：官方定位“complex problem-solving and agentic/vibe coding”；支持代码执行、URL Context、File Search 和函数调用。
- 深度推理与数学：动态 thinking_level（low/high）；官方文档强调 Pro 级推理，但不同 Preview 版本的 GPQA/AIME 数字在滚动更新，本文不混列旧版分数。
- 多模态：原生图像、视频、音频输入；配套 Nano Banana Pro/Flash Image 做图像生成，Gemini Live/Translate/TTS 覆盖实时语音。
- 长上下文：输入 1M、输出 64K；文档建议把问题放在长数据之后，并用 Context Caching、File Search 降低长上下文成本。
- Agent/工具：Google Search、Maps grounding、Code Execution、URL Context、File Search、Computer Use 和自定义 function calling。
- 开源/本地化：Gemini 权重闭源；Google AI Studio、Gemini API、Vertex AI 托管。
- 价格：$2 / $12（≤200K）；$4 / $18（>200K）。
- 依据：[Gemini 3 开发者指南](https://ai.google.dev/gemini-api/docs/gemini-3)、[模型列表](https://ai.google.dev/gemini-api/docs/models)、[长上下文说明](https://ai.google.dev/gemini-api/docs/long-context)。

### 4. xAI — Grok 4.7

- 发布时间/定位：2026-09-21；面向 Coding、知识工作和长任务自校验的旗舰。
- 编程：官方称在 CursorBench 4.0 价格/性能处于前沿；Grok 4.6 公开过 DeepSWE 1.1 65.9%、APEX-SWE 56.4%，4.7 的完整同口径表仍需等待更多第三方复测。
- 深度推理与数学：支持 reasoning 版本；官方重点展示长任务、自校验和知识工作，GPQA/AIME 不是其当前主要公开卖点。
- 多模态：Grok 产品支持图像/视频生成、图像理解和 Voice；API 模型能力随版本/端点区分。
- 长上下文：500K；达到 200K 输入后按长上下文档位计费。
- Agent/工具：实时 Web/X 搜索、Connectors、Grok Build、Cursor 集成，适合带搜索和代码执行的 Agent。
- 开源/本地化：Grok 4.7 权重闭源；主要通过 xAI API、产品和合作平台提供。
- 价格：短上下文 $2 / $6；长上下文 $4 / $12。
- 依据：[Grok 4.7 发布](https://x.ai/news/grok-4-7)、[API 定价](https://docs.x.ai/developers/pricing)。

### 5. Meta — Llama 4 Maverick / Scout

- 发布时间/定位：2025-04-05；当前仍是主流开放权重多模态家族。Maverick 偏质量/成本，Scout 偏单卡与超长上下文。
- 编程：Maverick 在官方横向中与 DeepSeek-V3 推理和 Coding 接近；不是闭源 Coding Agent 的最强项，但开放权重便于改造。
- 深度推理与数学：官方公布的教师模型 Behemoth 在 MATH-500、GPQA Diamond 超过 GPT-4.5、Claude Sonnet 3.7、Gemini 2.0 Pro；Behemoth 本身未开放。
- 多模态：Scout/Maverick 是原生图文模型；不提供原生视频生成和语音全双工能力，通常需外接模型。
- 长上下文：Scout 10M tokens；Maverick 1M 级别。超长窗口的有效检索质量要以具体量化模型、KV cache 和业务测试为准。
- Agent/工具：社区工具调用、Llama Stack、Transformers/vLLM/SGLang 生态成熟；官方产品 Meta AI 连接 WhatsApp、Messenger、Instagram。
- 开源/本地化：开放权重，可下载 Hugging Face/llama.com；Scout Int4 可放单张 H100，Maverick 适合单机多 GPU/云上部署。
- 价格：无统一官方 API 价格；云平台和推理供应商按算力/调用量报价。
- 依据：[Llama 4 官方发布](https://ai.meta.com/blog/llama-4-multimodal-intelligence/)。

### 6. Mistral — Mistral Large 4

- 发布时间/定位：2026-10 版本页当前列为最新 Large；开放权重、通用、多模态旗舰。
- 编程：Large 4 兼顾代码、结构化输出、函数调用；Mistral 另有 Devstral 2 专门做代码 Agent，若只看 SWE 任务应优先评估 Devstral 2。
- 深度推理与数学：可通过通用模型或 Magistral 系列完成推理；官方型号页没有给出统一的 GPQA/AIME 对比表。
- 多模态：原生图像/文档理解；语音、OCR、转写有独立 Voxtral/OCR 模型，视频通常通过外部预处理。
- 长上下文：Large 4 256K；官方限制页列明超窗请求直接返回 400，输入与输出共同计入窗口。
- Agent/工具：function calling、Agents & Conversations、structured outputs、Mistral Code/CLI 集成。
- 开源/本地化：开放权重，Apache 2.0 系列生态；可用 vLLM、SGLang、Transformers 私有化部署。
- 价格：Large 4 的官方当前卡片价格约 $0.5 / $1.5；具体区域/版本需以价格页为准。
- 依据：[模型总览](https://docs.mistral.ai/models)、[Large 3/4 说明](https://docs.mistral.ai/models/mistral-large-3-25-12)、[价格](https://docs.mistral.ai/inference/pricing)、[上下文限制](https://docs.mistral.ai/resources/known-limitations)。

## 二、国内厂商

### 1. DeepSeek — DeepSeek-V4.1-Flash / V4-Pro-0813

- 发布时间/定位：官方当前价格页已将 `deepseek-flash` 指向 V4.1-Flash、`deepseek-v4-pro` 指向 V4-Pro-0813；Flash 是性价比与多模态主力，Pro 是高质量推理主力。
- 编程：V3.1 曾公开 SWE-bench Verified 66.0%、Terminal-Bench 31.3%；V3.2 引入思考中的工具调用；V4 系列应以官方持续更新的评测页和实际代码 Agent 回归为准。
- 深度推理与数学：V3.2-Speciale 曾以 IMO/CMO/ICPC/IOI 金牌级结果定位；Speciale 为临时评测接口，不能当作当前常规生产型号。
- 多模态：V4.1-Flash 支持 Vision；Pro 当前价格页标注不支持 Vision。视频/语音需外接模型或产品能力。
- 长上下文：1M，最大输出 384K；官方同时提供 OpenAI/Anthropic 兼容接口。
- Agent/工具：V3.2 首次支持思考模式下多轮工具调用；V4.1-Flash/Pro 均支持 Tool Calls、Responses API、Anthropic API。
- 开源/本地化：V3.2 权重在 Hugging Face/ModelScope 开源，MIT 许可；V4.1 当前官方价格页未说明开放权重，部署需按版本确认。
- 价格：V4.1-Flash 输入缓存命中 $0.003（低峰）/未命中 $0.15、输出 $0.60；V4-Pro-0813 输入未命中 $0.66、输出 $1.98（低峰）。
- 依据：[当前模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)、[V3.2 发布](https://api-docs.deepseek.com/news/news251201/)、[V3.1 评测](https://api-docs.deepseek.com/updates/?release=deepseek-coder)。

### 2. 阿里云 Qwen — Qwen3.7-Max

- 发布时间/定位：2026 年滚动更新的 Max 旗舰；云端闭源 Max 与 Qwen3 开放权重家族并行。
- 编程/推理：Max 面向复杂 Coding、Agent 和通用推理；Qwen3 技术报告确认统一 thinking/non-thinking 模式。公开评测需区分 Max 云端型号与可下载 Qwen3 权重。
- 多模态：Max 主要为文本推理；图像/音视频由 Qwen-VL、Qwen-Omni 等专线模型承担。
- 长上下文：官方 Qwen API 页面当前标注 1,000,000 context；Alibaba Model Studio 的 qwen3-max 文档仍有 262,144 版本记录，接入前必须核对具体 model ID。
- Agent/工具：Function calling、结构化输出和阿里云 Model Studio/百炼工具编排；开放权重 Qwen3 生态可接 vLLM、SGLang、Ollama。
- 开源/本地化：Qwen3-235B-A22B、30B-A3B 等开放权重，适合企业私有化；Max 云端权重不开放。
- 价格：不同地域、版本和上下文档位差异较大；官方文档当前给出 qwen3-max 262K 计费表，不能用第三方聚合价替代。
- 依据：[Qwen API 当前型号页](https://qwen.ai/apiplatform)、[qwen3-max 官方文档](https://www.alibabacloud.com/help/en/model-studio/model-qwen3-max)、[Qwen3 技术报告](https://arxiv.org/abs/2505.09388)。

### 3. Moonshot AI — Kimi K2.5

- 发布时间/定位：2026-01；多模态、Agentic execution 和 Coding 旗舰，K2.5 权重已面向社区开放。
- 编程：强调视觉-代码协同和 Agent 执行，适合网页、GUI、文档与代码混合任务；公开 SWE 结果受 harness 影响，应以 K2.5 技术报告复现。
- 深度推理与数学：具备思考/规划能力，但公开资料对 GPQA/AIME 的统一报告少于 DeepSeek/Qwen。
- 多模态：原生图像和视频输入，支持视觉 Agent；语音不是 K2.5 的主打能力。
- 长上下文：262,144 tokens；长对话需要上下文裁剪和检索，不能把标称窗口当作全部可用记忆。
- Agent/工具：网页搜索、代码执行、浏览器/GUI 操作与多步 Agent 是核心卖点；Microsoft Foundry 已提供接入。
- 开源/本地化：Kimi K2.5 post-trained checkpoint 已发布；可通过 Hugging Face、vLLM/SGLang 生态部署。
- 价格：官方渠道、Foundry 和聚合平台价格不同；公开资料常见约 $0.5–$3 输入、$2–$12 输出档位，采购前应以 Moonshot 控制台为准。
- 依据：[K2.5 论文](https://arxiv.org/abs/2602.02276)、[Microsoft Foundry 介绍](https://techcommunity.microsoft.com/blog/azure-ai-foundry-blog/kimi-k2-5-now-in-microsoft-foundry/4492321)。

### 4. 智谱 AI — GLM-5.2 / GLM-5-Turbo

- 发布时间/定位：2026 年当前产品页主推 GLM-5.2 与 GLM-5-Turbo；GLM-5.2 偏旗舰通用与 Agent，Turbo 偏高吞吐/低价。
- 编程：官方定位 Coding、智能体、数理推理、PPT 生成均衡；目前公开 SWE-bench、GPQA、AIME 的可比同口径数据不足。
- 深度推理与数学：支持思考型调用和长任务拆解，适合中文知识工作；需通过自有题集和工具轨迹验证。
- 多模态：图像理解、文档/PPT 生成由产品体系提供；GLM-5 主模型公开资料更偏文本，视频/语音应按专用模型确认。
- 长上下文：官方型号页与不同渠道标注可能不同，常见为 128K 以上；实际可用性需按 API model ID 查询。
- Agent/工具：ZClaw/企业 Agent 方案提供工具协同、代码执行、定期任务和监控；支持标准函数调用。
- 开源/本地化：GLM 系列中有开放权重版本和 ModelScope/Hugging Face 生态；GLM-5.2/Turbo 的服务版权重是否开放需单独确认。
- 价格：GLM-5-Turbo 有按套餐和标准 API 两种口径；以智谱开放平台实时价目表为准，本文不把活动套餐折算为长期单价。
- 依据：[智谱 GLM-5.2/5-Turbo 页面](https://open.bigmodel.cn/claw-plan-team)。

### 5. MiniMax — MiniMax-M2.5

- 发布时间/定位：2026-02-12；面向真实生产任务的 Coding、Agent、搜索和 Office 全流程模型。
- 编程：SWE-bench Verified 80.2%、Multi-SWE-bench 51.3%；在 Droid harness 79.7、OpenCode 76.1，官方称达到 SOTA 级。
- 深度推理与数学：通过强化学习和任务分解提升复杂推理；公开重点不在 GPQA/AIME，适合用真实业务任务测量。
- 多模态：M2.5 主体偏文本/工具；Office Agent 可处理 Word/PPT/Excel，图像/视频/语音由 MiniMax 其他模型提供。
- 长上下文：官方产品强调长任务上下文管理；模型页面未给出统一可复用的最大 token 数，且 Agent 在超过最大上下文约 30% 时会丢弃历史，属于“实际可用性”重要限制。
- Agent/工具：原生搜索、代码执行、Office Skills、MiniMax Agent；支持 50/100 TPS 版本。
- 开源/本地化：权重已在 Hugging Face/GitHub 开放，推荐 vLLM、SGLang、Transformers、KTransformers 私有化部署。
- 价格：M2.5 约 $0.15 / $1.2；M2.5-Lightning 约 $0.3 / $2.4（官方博客按速率版本说明）。
- 依据：[M2.5 发布与 SWE 结果](https://www.minimax.io/news/minimax-m25)、[模型页与开源部署](https://www.minimax.io/models/text)。

### 6. 百度 — ERNIE 5.1

- 发布时间/定位：2026-05-09；百度当前主力通用模型，侧重中文、知识检索和原生全模态产品。
- 编程：官方发布稿称多项榜单领先，但公开资料未给出稳定、可复验的 SWE-bench 统一设置。
- 深度推理与数学：支持复杂问答和知识推理；GPQA/AIME 的公开同口径数据较少。
- 多模态：ERNIE 5.0/5.1 路线强调 native omni-modal，覆盖图像、语音、视频理解/生成的产品能力；API 端点需按模型区分。
- 长上下文：官方公开页面对 API 窗口与实际可用上限说明不如 OpenAI/Google 统一，接入前应查看千帆实时模型卡。
- Agent/工具：百度千帆、搜索增强、文心智能体和企业工作流；中文搜索与企业知识库是主要优势。
- 开源/本地化：主模型权重闭源；通过千帆、百度智能云和企业私有化方案提供。
- 价格：以千帆模型广场实时价为准；公开材料未形成稳定的国际美元统一价，本文不引用第三方报价。
- 依据：[ERNIE 5.1 发布](https://ernie.baidu.com/blog/posts/ernie-5.1-0508-release/)、[ERNIE 5.0 全模态披露](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0226/2026022600493.pdf)。

## 三、组内横向总结

### 国外厂商

| 维度 | 当前更强/更适合的选择 | 判断依据与边界 |
|---|---|---|
| 编程 | Claude Opus 4.7、GPT-5.6 Sol | Claude 官方 SWE-bench 87.6%；GPT-5.6 在 Terminal-Bench、Codex 工具链强。不同 harness 不可直接相减。 |
| 深度推理/数学 | Claude Opus 4.7、Gemini 3.1 Pro、GPT-5.6 Sol | Claude 有 GPQA 94.2% 公开数据；Gemini/GPT 的长推理与工具使用强，但公开数字口径不完全一致。 |
| 多模态 | Gemini 3.1 Pro | 原生图像/视频/音频输入，加上 Live、TTS、图像生成和工具生态最完整。 |
| 长上下文 | Meta Llama 4 Scout（标称 10M），GPT-5.6/Gemini 3.1（1M 级） | 标称窗口不等于召回质量；Scout 的本地显存和量化约束需要实测。 |
| Agent/工具 | GPT-5.6 Sol、Claude Opus 4.7、Gemini 3.1 Pro | 三者均有函数调用、搜索、代码执行、计算机操作或 MCP；Anthropic 在长轨迹和 MCP 评测突出。 |
| 开源/本地化 | Llama 4、Mistral Large 4 | Llama 生态最大；Mistral Apache 2.0/开放权重更利于企业私有化。 |
| 性价比 | Mistral Large 4、Gemini 3.1 Pro、GPT-5.6 Terra/Luna | Mistral $0.5/$1.5 最低的旗舰档之一；Gemini 3.1 Pro 兼顾 1M 上下文；OpenAI Terra/Luna 适合分层路由。 |

## 四、选型结论

1. 追求最高代码 Agent 质量：优先 Claude Opus 4.7 或 GPT-5.6 Sol；需要中文、低成本和可控部署时，先测 MiniMax M2.5、DeepSeek 和 Qwen。
2. 需要视频/音频/图像一体化：优先 Gemini 3.1 Pro；国内场景优先 Kimi K2.5、ERNIE 5.1 或 Qwen Omni/VL 组合。
3. 需要私有化：优先 Llama 4、Mistral Large 4、Qwen 开放权重、DeepSeek V3.2、MiniMax M2.5；闭源旗舰只能走托管 API 或商业私有化方案。
4. 需要百万级上下文：先确认输入、输出、思考 token 是否共享，以及超过阈值后的价格；再用真实长文档/代码库做检索召回、跨段推理和工具轨迹测试。
5. 需要控制成本：采用“旗舰 + 低价模型”路由。国外可用 GPT-5.6 Sol/Terra/Luna 或 Gemini Pro/Flash，国内可用 DeepSeek Flash + MiniMax M2.5/Qwen 中型模型。
